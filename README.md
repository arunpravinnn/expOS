# eXpOS Case Study 

I am `Arun Pravin A P` `(CB.SC.U4CSE24710)` from CSE H, School of Computing, Amrita Vishwa Vidyapeetham, Coimbatore.


This repository contains my work on **eXpOS (Experimental Operating System)** carried out as part of the course  
`23CSE214 – Operating Systems (2025–26 Even Semester)`.


The implementation follows the official **[eXpOS roadmap](https://exposnitc.github.io/Roadmap.html)** by NIT Calicut, completed up to **Stage 10**, using the **XSM (eXperimental String Machine)** environment.
